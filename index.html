This is how I would approach an executive presentation review, matched to the way I already work with leadership teams.

  1. Reconstruct

    Rebuild the slide in PowerPoint from the source image, with clean structure and consistent alignment.

  2. Sharpen the message

    Rewrite titles as action titles, set the message hierarchy and choose the chart that fits the data.

  3. Log the reasoning

    Record each change and why, and say plainly which elements I left alone and why.

  4. Deliver on time

    Return the finished slide and change log together, within the assignment window.
